# GameBro
Custom portotive gaming console with Android OS, 5 buttons, joystick and display. I did this for playing minecraft Pocket edition and other games.

# Why I did this
I like minecraft and at school teachers before lesson take form students phones. This console is good for spent boring time (I don't play in lesson time don't worry)
# Features
1. This is full station for Android.
2. You can just install all games which you want and download to this!
3. Very cool :D.
4. With joystick you can control the mouse like in windows.
5. Compack: Easy to take outside
# How it works
The **Rodxa CM5** is full android station so almost all works do this Rodxa. And this 5 buttons and joystick connected to **Raspberry pi pico** and pico controls only this. **I don't place Wifi and Bluetooth module** because I don't think it's very important and you can just econome in this.
# How to assemble
1. Order PCB form JLCPCB
2. Order all parts for this GameBro (You can find parts in BOM)
3. Solder parts to PCB
4. Print CAD
5. And just assemble all of this
